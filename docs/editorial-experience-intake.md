# RoadToKorea 도시 경험 수집표

작성 형식: `도시 — 경험 유형 — 기억나는 한 줄`

경험 유형 예시: 현재 거주, 과거 거주, 가족 연결, 반복 방문, 1회 방문, 수학여행, 업무 방문, 경유, 방문 없음.

정확한 기억이 없는 도시는 비워 두세요. 오래된 경험은 오래된 경험이라고 표시하고, 현재 가격·교통·운영시간의 근거로 사용하지 않습니다.

## 한 줄을 조금 더 좋게 적는 힌트

- 장소: 어느 동네, 시장, 바다, 길, 역 앞이 기억나는지
- 감각: 계절, 냄새, 소리, 이동 경로, 시간대 분위기 중 하나
- 행동: 무엇을 먹었는지, 어떻게 이동했는지, 어디에서 쉬었는지
- 변화: 예전과 지금이 다르다고 느낀 부분
- 판단: 다시 간다면 무엇을 하고 무엇을 건너뛸지

개인 주소, 가족 이름, 학교 이름처럼 공개하고 싶지 않은 정보는 적지 마세요.
